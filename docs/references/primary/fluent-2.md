# Microsoft Fluent 2 reference pack

## Source and licensing

- Official design site: https://fluent2.microsoft.design/
- Official React components: https://react.fluentui.dev/
- Source and MIT license: https://github.com/microsoft/fluentui

This repository stores local analysis and links, not Microsoft assets or documentation copies.

## Transferable strengths

- Modern productivity surfaces that scale from focused tools to application shells.
- Soft depth, precise iconography, and responsive hover/focus treatment.
- Cross-platform accessibility and interaction discipline.
- Application-shell consistency across large product areas.

## Local adoption

- Depth separates working surfaces without placing every region in a heavy card.
- Small hover, focus, selection, and transition responses keep neutral pages alive.
- Medium and large systems retain stable global identity while modules vary within limits.
- Icons support scanning but do not replace labels for unfamiliar actions.

## Rejected defaults

- Windows-specific identity and platform conventions are not web defaults.
- Acrylic/translucency is not used where it harms contrast or performance.
- Depth does not become decorative shadow on every container.

## Influenced artifacts

- Shared shell, Control rail, full-screen workspace, and conversation examples
- `src/styles/index.css` surface hierarchy and micro-interactions
- Large-platform configuration rules
