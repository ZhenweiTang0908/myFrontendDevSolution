# IBM Carbon reference pack

## Source and licensing

- Color and themes: https://carbondesignsystem.com/elements/color/overview/
- Typography strategies: https://carbondesignsystem.com/elements/typography/style-strategies/
- Motion: https://carbondesignsystem.com/elements/motion/overview/
- Source and Apache-2.0 license: https://github.com/carbon-design-system/carbon

This repository records principles and links. It does not copy Carbon components or IBM brand assets.

## Transferable strengths

- Role-based color and layered surfaces for professional products.
- Productive versus expressive typography and motion.
- Rigorous data, grid, visualization, and accessibility guidance.
- Neutral-dominant themes with purposeful action and status color.

## Local adoption

- Calm and expressive motion are distinct configuration modes.
- Data pages use aligned numbers, stable scanning, and layered surfaces.
- Help/marketing moments may use more expressive type than dense work areas.
- Theme roles remain stable while values change.

## Rejected defaults

- IBM Plex and IBM identity are not mandatory.
- Carbon’s enterprise grid does not override embedded or narrow tool needs.
- Product pages do not inherit complexity solely because Carbon supports it.
